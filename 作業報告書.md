## 今回の変更

### Source of Truth

新規:

- `project-meta.json`
- `SPEC.md`

Guide Version / Profiles / Storage Schema / AI Handoff Schema / GitHub Pages base pathを明示した。

READMEは現在の利用方法中心へ整理し、詳細仕様は`SPEC.md`、変更とVerification Stateは本ファイルへ分離した。

### Storage Schema / Compatibility

`js/storage.js`へSchema Version付き保存を追加。

新規保存形式:

```text
vreview-storage
├─ schemaVersion
├─ revision
├─ updatedAt
└─ data
```

v0.5.0以前のplain Array / Object形式も読み込めるため、既存Draftを強制削除しない。

破損JSONは可能ならRecovery keyへrawを退避し、元データを即上書きしない。

### Draft Backup / Restore

既存Draftから新規開始する場合:

```text
既存Draft
↓
Backup
↓
新規開始
```

main Draftがない状態でBackupが残っていれば、同じ動画選択時に復元できる。

### Destructive Action

Scene削除へ`元に戻す`を追加。

### Storage Failure / Multi-tab

- localStorage read / write / schema / migration / backup失敗をEvent化
- New Review上で保存失敗を表示
- 同一動画Draftが別タブで更新された場合、競合警告を表示

完全な自動Mergeは未実装。

### AI-HANDOFF Import Validation

新規:

- `data/detector-feedback-schema.json`

Detector Testで以下をImport前Validationする。

- Package schema / Version
- 必須JSON
- ZIP size / entry数 / JSON size
- Scene数
- Start / End
- feedback label
- review tier
- source
- confidence
- ZIP内Path
- JSON構文

既存Feedback v4 / v5を対応対象とする。

ZIP解析では集計不要のJPEG等をMemoryへ保持せず、必要JSONだけ読むよう変更した。

### DOM Safety

Import由来Clip名等は`textContent`中心で描画。

Video metadataもHTML文字列連結をやめ、DOM + `textContent`へ変更。

### UI State

New Review:

- Loading
- Video Error
- Storage Error
- Draft Restore
- Backup Restore
- Detector Error + 手動復帰
- Feedback ZIP Error

Detector Test:

- Empty
- Loading / Validation
- Error
- Success

を明示した。
